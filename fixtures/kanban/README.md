# Kanban north-star fixture

This fixture captures the assumed final Waluau source for the CSR Kanban demo
tracked by `waluau-9myi` and `waluau-oa5n`.

It is intentionally not part of the current conformance suite. The source uses
future browser host interop features tracked by beads:

- `waluau-rw8e` host function declarations
- `waluau-oeb5` extern host-object types
- `waluau-s21a` nullable extern references
- `waluau-6mcb` method dispatch on extern host objects
- `waluau-3nm7` minimal DOM and localStorage host API
- `waluau-4s72` Waluau callbacks as browser event handlers

The goal is to keep the desired end-state concrete while the language and host
runtime pieces are implemented.
