# tree-sitter-waluau

A tree-sitter grammar for Waluau, written against the language as the
compiler implements it (`crates/waluau-lexer`, `crates/waluau-parser`). It is
the syntax foundation for the repo-local Zed extension in
`.zed/extensions/waluau`, which references this directory through
`[grammars.waluau]` in its `extension.toml`.

The grammar covers the whole surface: typed declarations (`local`/`const`
bindings, `<const>` attributes, `function` forms including `A.b` statics and
`A:b` methods, `export function`), `type`/`opaque type`/`enum` declarations,
interface conformance (`I & { ... }`), tagged unions and `is` tests, `::`
casts, `match ... case` statements, if-cast bindings (`if Type(x) = e then`),
`declare function`/`property`/`const` directives, backtick string
interpolation, bytes literals, and long-bracket strings and comments.

Contextual keywords follow the compiler: `const` uses the same two-token
lookahead (implemented in the external scanner), so `local const = 1` and
`const = 2` stay ordinary statements about a variable named `const`.

## Layout

- `grammar.js` — the grammar definition
- `src/scanner.c` — external scanner for `[[...]]`/`--[[...]]` long brackets
  (any `[=*[` level) and the contextual `const` keyword
- `src/parser.c`, `src/grammar.json`, `src/node-types.json` — generated by
  `tree-sitter generate`; committed because Zed compiles the grammar from
  `src/` at install time
- `test/corpus/` — grammar regression tests

## Develop

```sh
cd tools/tree-sitter-waluau
npx -y tree-sitter-cli@0.25.8 generate --abi 14
npx -y tree-sitter-cli@0.25.8 test
```

The whole-repository check parses every non-vendored `.walu` file (the
vendored Luau suite under `conformance/luau/` is a different dialect):

```sh
find conformance engine apps examples check builtins externs fixtures \
  -name "*.walu" -not -path "conformance/luau/*" \
  | xargs -I{} npx -y tree-sitter-cli@0.25.8 parse --quiet {}
```

The only expected failure is `conformance/const_requires_initializer.walu`,
which exists to be a parse error.

After changing the grammar, regenerate `src/`, commit, push, and then bump
`[grammars.waluau].commit` in `.zed/extensions/waluau/extension.toml` to the
landed commit — Zed fetches the grammar from the repository at that pin.
